# 评测方法与范围

## 问题
同一组摄影作品和公开背景说明下，模型会如何选择年度冠军？评语反映了怎样的观察与权衡？这是一项探索性内容实验，不是标准化审美基准。

## 候选集
第62届成年组16类别：13张单幅类别冠军，3张获奖组照公开展示代表图。C05、C12、C15并未确认为评委内部指定的年度参评单幅。仅重建公开材料范围，不宣称复刻完整官方候选池。早期16张预览实验不属于本仓库此轮数据。

## 输入
16张官方图片，顺序C01到C16；每图对应`dataset/captions-input.en.txt`英文背景、地点、器材；共同提示词见`prompts/judge.zh.txt`。图片保留官方署名，说明仍可能含作者名字，非完全匿名。禁止联网及利用已知结果属于提示词要求，不保证消除训练数据记忆。维护方映射和结果不要发给被测模型。

## 评价
原创性、叙事表达和伦理实践；没有固定权重、没有数字评分。逐件约250—350字，要求区分可见事实、说明背景与推测；前三名及唯一冠军并解释权衡。完整原始提示词是实际执行依据，不新增维度权重。

## 运行
每模型一次成功独立评选，日期2026-10-14。GPT、Opus为用户提供的桌面端报告；Gemini与Seed为API调用，通道和推理设置不完全统一。GPT后端型号未独立核验；Opus型号由报告记载。API名称以保存的返回元数据为准，不由本文推断公开可用性。

Gemini：native inline images，maxOutputTokens=16384，未显式设temperature/seed，未配置搜索工具。Seed：原生16图image_url输入，max_tokens=16384，stream=true，未显式配置temperature/seed/thinking，未配置搜索工具。桌面端温度、seed和内部压缩策略未记录。没有重复实验或顺序平衡，不能报告稳定性、显著性或总体准确率。

## 复现
先备齐合法取得的16张图片并按ID命名；核对哈希；独立新会话上传图片与英文说明，粘贴共同提示词，关闭搜索。确认模型实际查看全部16图，保存完整回复、实际型号/界面标签、日期、设置和缺图情况。建议先提交自己的结果，再看本仓库答案。不同型号或不同背景资料应记为新条件，不覆盖本轮。

## 解释边界
官方没有逐项评分或年度第二第三名，只有冠军与公开评语。模型与官方一致不等于审美正确，不一致也不等于能力不足。提示词要求不将死亡、悲伤或拍摄难度自动换算成高评价，可能影响选择，尚无对照实验。

原报告中“母象”“绝对首次”“零侵扰”“具体非法死因”等可能超出来源证据，应独立检查。雌象与幼象的亲缘关系未确认。官方公开资料、模型可见材料和内部评审所掌握的信息不完全相同。
