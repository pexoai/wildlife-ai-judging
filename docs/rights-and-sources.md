# 来源与权利

比赛：[Wildlife Photographer of the Year](https://www.nhm.ac.uk/wpy/gallery)。
规则：[成年组规则](https://www.nhm.ac.uk/wpy/wpy/competition/rules)。
年度结果：[官方公告](https://www.nhm.ac.uk/press-office/press-releases/heartbreaking-photograph-of-an-elephant-and-deceased-calf-wins-wpy.html)。

图片版权属于各摄影师，官方展示不等于向本项目授予GitHub再分发许可。因此仓库不包含照片、缩略图或嵌图，也不包含视频、声音克隆样本、配乐或内部制作资料。作品清单提供作者、官方页面和原始输入文件SHA-256，便于从权利方允许的渠道取得图片后核对。官方页的版权说明可见[图库示例](https://www.nhm.ac.uk/wpy/gallery/2019-show-time)。

`dataset/captions-input.en.txt`是本轮实际使用的官方英文作品背景及器材文本，按编号保留以复现输入；每项来源见manifest。它是第三方来源材料，不适用本仓库MIT许可；使用者应遵守原权利方条件。JSON清单不是原图开放许可。

项目独立制作，与NHM、比赛及各模型厂商无隶属、赞助或认可关系。公开模型报告是本次实验的输出，包含可能的事实错误，不代表官方评价。
